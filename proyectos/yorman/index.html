Guía de Instalación de Fail2Ban

Protege tu servidor Linux contra ataques de fuerza bruta.

  • Requisitos
  • Instalación
  • Configuración
  • Verificación

Requisitos

  • Servidor con Linux (Debian, Ubuntu, etc.)
  • Acceso root o sudo

Instalación

sudo apt update  
sudo apt install fail2ban

Configuración Básica

Edita el archivo /etc/fail2ban/jail.local para definir reglas:

[sshd]  
enabled = true  
port = ssh  
filter = sshd  
logpath = /var/log/auth.log  
maxretry = 3

Verificación

Reinicia el servicio y verifica su estado:

sudo systemctl restart fail2ban  
sudo fail2ban-client status
