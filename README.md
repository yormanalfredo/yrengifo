
# 🚀 Instrucciones para la Actividad con Git 

Bienvenidos al repositorio **[actividad GIT!]** 👨‍💻👩‍💻  
Este repositorio privado está diseñado para que cada funcionario practique y contribuya con código de forma organizada y colaborativa utilizando Git.

---

## 🧭 Flujo de Trabajo y Reglas Generales

### 1️⃣ Creación de Ramas Individuales

Cada funcionario debe crear una **nueva rama** con su nombre.  
Por ejemplo:

```bash
git checkout -b pepe
```

---

### 2️⃣ Desarrollo de Proyecto

- En su **rama personal**, cada funcionario debe desarrollar una **página sencilla** utilizando como mínimo **HTML y CSS nativo**.
- El desarrollo debe incluir al menos **5 commits** en su rama personal y un archivo .md haciendo una introducción su proyecto.

---

### 3️⃣ Integración al Repositorio Principal

- Una vez finalizado el desarrollo, deben hacer **merge** de su rama personal a la rama `main`.
- Su proyecto debe colocarse dentro de la carpeta `proyectos`, en una **subcarpeta con su nombre**.

📁 Estructura esperada:
```
proyectos/
└── pepe/
    ├── index.html
    └── estilos.css
```

---

✅ **¡Sigue estos pasos para asegurar una colaboración ordenada y efectiva con Git!**  
Si tienes dudas, no dudes en preguntar. ¡Mucha suerte! 💻✨
